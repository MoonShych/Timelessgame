# TIMELESS — บันทึกข้ามกาลเวลา
เกม Visual Novel 2D แนว Sci-fi / Time Travel / Educational Quiz
สร้างด้วย HTML5 + CSS3 + Vanilla JavaScript เท่านั้น (ไม่มี Framework, ไม่มี Library ภายนอก, ไม่ต้องใช้ Backend)

---

## 1. วิธีเปิดเกมใน VS Code (สำหรับมือใหม่)
1. แตกไฟล์ ZIP แล้วเปิดโฟลเดอร์ `TIMELESS` ด้วย VS Code (File → Open Folder)
2. ติดตั้งส่วนเสริม **Live Server** (Ctrl+Shift+X → ค้นหา "Live Server" ของ Ritwick Dey → Install)
3. คลิกขวาที่ `index.html` → **Open with Live Server**
4. เบราว์เซอร์จะเปิดเกมขึ้นมาเอง และรีเฟรชอัตโนมัติเมื่อคุณบันทึกไฟล์

**เปิด `index.html` โดยดับเบิลคลิกได้ไหม?** ได้ เกมทำงานได้ครบ เพราะไม่ได้ใช้ ES Module หรือ fetch
ข้อสังเกต: บางเบราว์เซอร์อาจจำกัด LocalStorage เมื่อเปิดแบบ `file://` ถ้า Save/Continue ไม่ทำงาน
เกมจะแจ้งเตือนและเล่นต่อได้ตามปกติ — ให้เปิดผ่าน Live Server แทน

## 3. วิธีแก้เนื้อเรื่องใน story.js
เปิด `js/story.js` เนื้อเรื่องคือกลุ่มของ "เหตุการณ์" ที่อ้างอิงกันด้วย ID:
```js
start: {
    id: "start", type: "dialogue",
    background: "future_lab",
    character: "luna", expression: "surprised", position: "right",
    speaker: "ลูน่า", text: "ยินดีต้อนรับสู่โลกอนาคต!",
    next: "intro_02"        // ← ID ของเหตุการณ์ถัดไป
},
```
คำอธิบายทุกฟิลด์อยู่ในคอมเมนต์ด้านบนของ `story.js` ประเภทเหตุการณ์ที่มี:
`dialogue` (บทสนทนา), `choice` (ตัวเลือก), `quiz` (คำถาม), `condition` (แยกทางตามตัวแปร), `set` (ตั้งตัวแปรเงียบ ๆ), `ending` (ฉากจบ)

ถ้า `next` ชี้ไปยัง ID ที่ไม่มีอยู่ เกมจะขึ้นข้อความแจ้งเตือนภาษาไทย (ไม่ค้าง) และเปิด Console (F12) จะเห็นรายการ ID ที่ผิดทั้งหมดตั้งแต่เปิดเกม

## 4. วิธีเพิ่มเหตุการณ์และกำหนดเส้นทางเนื้อเรื่อง
**เพิ่มบทสนทนา:** เพิ่มเหตุการณ์ใหม่ใน `storyData` แล้วให้เหตุการณ์ก่อนหน้าชี้ `next` มาที่ ID ใหม่
**ตัวเลือกแยกทาง:**
```js
choice_02: { id: "choice_02", type: "choice", speaker: "ลูน่า", text: "จะไปทางไหน?",
  choices: [
    { text: "ทางซ้าย", next: "left_path", set: { trust: true } },
    { text: "ทางขวา", next: "right_path", add: { points: 1 } },
    { text: "ทางลับ", next: "secret", requires: { var: "trust", op: "==", value: true } }  // แสดงเมื่อเข้าเงื่อนไข
  ] },
```
**แยกทางตามตัวแปร (ไม่ใช้ eval):**
```js
check_score: { id: "check_score", type: "condition",
  if: { var: "score", op: ">=", value: 4 }, then: "good_end", else: "bad_end" }
```
`op` ที่ใช้ได้: `==  !=  >  >=  <  <=` รวมเงื่อนไขด้วย `all`, `any`, `not` ได้
หลายเงื่อนไข: ใช้ `branches: [{ if: {...}, next: "a" }, { if: {...}, next: "b" }], else: "c"`
**ตัวแปรที่ระบบสร้างให้:** `score`, `correct`, `wrong` และหลังจบแต่ละชุดคำถาม `<ชื่อชุด>_correct`, `_wrong`, `_score`, `_passed`
**ฉากจบ:** `type: "ending"` ใส่หลายฉากจบได้ ถ้าใส่ `next` จะมีปุ่ม "เล่นต่อ"

## 5. วิธีเพิ่มคำถามใน questions.js
```js
{
  id: "it_q005",
  question: "คำถามของคุณ?",
  options: ["ตัวเลือกแรก", "ตัวเลือกสอง", "ตัวเลือกสาม"],   // 2 ตัวเลือกขึ้นไป ไม่จำกัดว่าต้อง 4
  answer: 1,            // เริ่มนับจาก 0 → 1 คือ "ตัวเลือกสอง" (คำตอบถูกอยู่ตำแหน่งไหนก็ได้)
  explanation: "คำอธิบายเฉลย"
}
```
ตั้งค่าระดับชุดคำถาม: `requiredCorrect`, `pointsPerQuestion`, `showExplanation`, `allowRetry`, `shuffleQuestions`, `shuffleOptions`
(รายละเอียดอยู่ในคอมเมนต์หัวไฟล์) ถ้าเปิดสุ่มตัวเลือก ระบบจัดตำแหน่งคำตอบถูกให้อัตโนมัติ
ใช้ชุดคำถามในเนื้อเรื่อง:
```js
question_01: { id: "question_01", type: "quiz", questionSet: "it_basics", passNext: "pass_01", failNext: "fail_01" }
```
ต่อคำถามเลือกกระโดดทันทีได้ด้วย `correctNext` / `wrongNext`
เกณฑ์ผ่านที่ไม่ได้ระบุ = ต้องตอบถูกทุกข้อ

## 6. วิธีเพิ่มตัวละครและสีหน้าใหม่
1. เพิ่มในตาราง `characterList` ที่ `js/characters.js`: `mika: { name: 'มิกะ', color: '#ffb3d9', hair: '#5a2a4a' }`
2. ใส่ภาพ PNG ใน `assets/characters/` ตั้งชื่อ `<id>_<สีหน้า>.png` เช่น `mika_normal.png`, `mika_happy.png`
3. ใช้ใน story.js: `character: "mika", expression: "happy", position: "left"`
   สีหน้าคือชื่ออะไรก็ได้ที่ตรงกับชื่อไฟล์ หลายคนพร้อมกัน: `show: [{ character:"luna", position:"right" }, { character:"mika", position:"left" }]`
   ซ่อนตัวละคร: `hide: ["luna"]` หรือ `hide: "all"`
ไม่มีไฟล์ภาพ = เกมวาดภาพสำรอง (เงาตัวละครพร้อมสีหน้า) ให้ ไม่ทำให้เกมหยุด
คำแนะนำภาพ: PNG โปร่งใส สูงประมาณ 1200px ทุกสีหน้าขนาดเท่ากัน

## 7. วิธีเพิ่มฉากหลังใหม่
1. ใส่ภาพ (JPG แนะนำ 1920×1080) ใน `assets/backgrounds/`
2. เพิ่มในตาราง `backgroundList` ที่ `js/backgrounds.js`: `library: { file: 'library.jpg', fallback: 'linear-gradient(...)' }`
3. ใช้: `background: "library"` ใน story.js
ไม่มีไฟล์ภาพ = ใช้ `fallback` (พื้นหลังไล่สี CSS) แทน

## 8. เสียง
วางไฟล์ใน `assets/audio/` แล้วอ้างชื่อใน story.js: `bgm: "theme_main"` (เล่น `theme_main.mp3`), `sfx: "click"`, หยุดเพลง `bgm: null`
ไม่มีไฟล์เสียง = เกมเล่นต่อได้ตามปกติ  เพลงจะไม่เล่นจนกว่าผู้เล่นคลิกครั้งแรก (ตามกฎของเบราว์เซอร์)
นามสกุลอื่นที่ไม่ใช่ mp3 ให้ใส่นามสกุลเต็ม เช่น `bgm: "theme.ogg"`

## 9. วิธีเพิ่มวิชาใหม่ในอนาคต
1. เขียนเนื้อเรื่องชุดใหม่เป็นตัวแปรใหม่ใน `story.js` เช่น `const mathStory = { start: {...}, ... }` (ID ซ้ำกับวิชาอื่นได้)
2. เพิ่มชุดคำถามใน `questions.js` เช่น `math_basics: {...}`
3. ลงทะเบียนในตาราง `subjects` ท้ายไฟล์ `story.js`:
```js
math: { title: "คณิตศาสตร์", description: "...", cover: "classroom", start: "start",
        questionSets: ["math_basics"], story: mathStory }
```
เมื่อมีมากกว่า 1 วิชา เกมจะให้ผู้เล่นเลือกวิชาตอนกด New Game และบันทึกฉากจบแยกตามวิชา **ไม่ต้องแก้ engine.js**

## 10. ฟีเจอร์ที่ทำงานได้จริง (ผ่านการทดสอบอัตโนมัติด้วย jsdom — 45 รายการ)
- Main Menu, New Game, Continue (ปิดใช้งานเมื่อไม่มีเซฟ), Settings, Credits
- บทสนทนา พิมพ์ทีละตัวอักษร ขึ้นบรรทัดใหม่อัตโนมัติ คลิกเพื่อแสดงทั้งหมด/ไปต่อ
- ตัวละครหลายคนพร้อมกัน ซ้าย/กลาง/ขวา เปลี่ยนสีหน้า ย้ายตำแหน่ง ซ่อน และภาพสำรองเมื่อไม่มีไฟล์
- ฉากหลัง Fade และฉากสำรองด้วย CSS
- ตัวเลือก (มีเงื่อนไข `requires`), ตัวแปรเนื้อเรื่อง, เงื่อนไข `condition` โดยไม่ใช้ eval
- ระบบคำถาม: จำนวนตัวเลือกยืดหยุ่น, สุ่มคำถาม/ตัวเลือก (จัดตำแหน่งคำตอบถูกให้ตรง), เฉลย+คำอธิบาย, คะแนน, เกณฑ์ผ่าน, ตอบใหม่ได้, กระโดดเหตุการณ์ตามผลลัพธ์, กันส่งคำตอบซ้ำ, ไม่เปิดเฉลยก่อนตอบ
- ฉากจบหลายแบบ + เล่นต่อ/เล่นใหม่/กลับเมนู
- Save/Load 3 ช่อง + บันทึกอัตโนมัติ (ใช้กับ Continue) เก็บเหตุการณ์ ความคืบหน้าคำถาม คะแนน ตัวแปร ตัวละคร ฉากหลัง เพลง และ Backlog; ข้อมูลเสียหายจะไม่ทำให้เกมค้าง
- Backlog (ไม่เก็บซ้ำ และไม่เปลี่ยนสถานะเกม)
- Auto Mode (ปรับความเร็ว, หยุดที่ตัวเลือก/คำถาม/ฉากจบ) และ Skip (ข้ามเฉพาะข้อความที่อ่านแล้ว, หยุดที่ข้อความใหม่/ตัวเลือก/คำถาม)
- ตั้งค่าเสียง ความเร็วข้อความ Auto เอฟเฟกต์เปลี่ยนฉาก เก็บใน LocalStorage
- ตรวจ ID เหตุการณ์ผิดพลาดพร้อมข้อความภาษาไทย
- รองรับคีย์บอร์ด: Space/Enter/→ ไปต่อ, 1–9 เลือกตัวเลือก, A–D หรือ 1–4 เลือกคำตอบ, Esc เปิด/ปิดเมนู
- UI รองรับมือถือ/คอมพิวเตอร์ ถูก/ผิดมีไอคอน ✓ ✗ และข้อความกำกับ ไม่พึ่งสีอย่างเดียว

## 11. ข้อจำกัดที่ยังเหลืออยู่ (บอกตรง ๆ)
- **ยังไม่ได้ทดสอบในเบราว์เซอร์จริง** การทดสอบทำใน jsdom (จำลอง DOM) จึงยังไม่ได้ตรวจความสวยงามของ CSS บนหน้าจอจริง, การเล่นเสียงจริง และการสัมผัสบนมือถือ — โปรดเปิดทดสอบด้วยตนเองและลองย่อหน้าจอ
- ไม่มีไฟล์ภาพ/เสียงจริงมาให้ ใช้ภาพสำรองที่วาดจากโค้ดแทน
- เนื้อเรื่องตัวอย่างสั้นมากเพื่อทดสอบระบบเท่านั้น
- ข้อความ "ที่อ่านแล้ว" เก็บแยกตามเครื่อง/เบราว์เซอร์ (LocalStorage) ไม่ผูกกับช่องเซฟ
- ถ้าแก้ ID ในเนื้อเรื่องหลังมีเซฟเก่า เซฟนั้นอาจโหลดไม่ได้ (เกมแจ้งเตือน ไม่ค้าง)
- ฟอนต์ใช้ฟอนต์ไทยที่มีในเครื่อง (Sarabun / Noto Sans Thai / Tahoma) เพราะห้ามใช้ทรัพยากรภายนอก
